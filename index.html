Why an AI-agnostic approach

The best model changes every few months. Your platform shouldn't have to.

A year ago the default was Cursor. Today many teams talk about Claude. Next year it could be another provider. Standardizing on a single model vendor ties your developer tooling, contracts and cost structure to one roadmap.

Choice

Pick the model per task

Claude Opus, Sonnet and Haiku run natively in Copilot next to GPT, Gemini, MAI, Grok and Kimi. New models often land on day one. Auto mode can pick one for you.

Continuity

Nothing to unlearn

CLAUDE.md, AGENTS.md and MCP servers carry over. Teams that like Claude keep using Claude, now inside a governed platform.

Economics

Match cost to the work

Send routine, high-volume work to low-cost models and save frontier models for the hard problems. A single-vendor tool can only move you up and down one price ladder.

Powered by HydraFusion

From choosing a model to orchestrating several Research preview

HydraFusion is GitHub Copilot's runtime orchestration layer. You select it like any other model. For each request it builds an execution plan across models from multiple providers, using extra model calls only when they're likely to improve the result. GitHub Blog

PATTERN 1

Single

One model solves the task directly. Fastest and cheapest when one model is a clear fit.

PATTERN 2

Cascade

An efficient model drafts first. A quality gate accepts the result or escalates to a stronger model.

PATTERN 3

Critique

One model drafts, a critic from a different model family reviews it read-only, and the drafter revises once.

Built for repository-level work

  • Complete accounting. Cost is tracked across every leg: draft, critique, revision, escalation, retry.
  • Bounded execution. Each leg has explicit timeout and cancellation limits.
  • Isolated review. Critics run tool-less and can't modify the repo.
  • Fail-safe. No patch is applied if the workflow fails validation.
  • Pay for what runs. Billing follows the tokens each model actually uses.

Where Claude is strong

Claude models are strong at deep multi-file agentic work, and Claude Code, its CLI, is fast and scriptable for power users who live in the terminal. Claude has real momentum with AI-forward teams, and for a single developer happy with one model vendor, it's a good choice.

Why Copilot fits the enterprise

When you're standardizing hundreds of developers, the questions shift to governance, spend control and lock-in. Copilot has the Copilot CLI for terminal users, runs the same Claude models, and adds the platform, controls and commercial terms around them.

Where Claude can cost more at scale

A higher price floor

The cheapest Claude option is Haiku 4.5 at $1 input / $5 output per 1M tokens. Copilot's low-cost tier starts at $0.20 / $1.20 (MAI-Code-1.1-Flash) or $0.10 / $0.50 (GPT-6 Luna). At thousands of daily agent runs, that gap compounds.

Heavy use adds up

Anthropic estimates Claude Code at about $13 per active developer-day, roughly $150 to $250 per developer per month for typical use. Anthropic docs

No pooling across users

Each Copilot Business seat includes 1,900 AI credits ($19 of usage) for any model, pooled across teams and cost centers. Heavy users draw on capacity light users don't consume, so less is stranded.

A second contract to manage

Claude is billed directly by Anthropic, outside your Microsoft commitment. Copilot seats and overage draw down MACC on one Microsoft bill, with your existing Azure discount terms applying.

Actual savings depend on Customer's model mix, usage volume and contract terms. We recommend a short pilot that tracks token usage by model to size the difference with your own data.

Copilot code review

Copilot reviews the pull request in minutes and leaves inline comments with suggested changes. You can request it on a PR or run it automatically on every PR with rulesets.

For developers: first-pass feedback arrives right away. Human reviewers spend their time on design and logic, not nitpicks.

Add-on · $10 per active committer / month + AI usage

GitHub Code Quality

Combines CodeQL analysis with AI detection to flag maintainability and reliability issues in the PR, with one-click Copilot Autofix. Also adds org-wide quality scores, test coverage shown on each PR, and merge gates you can run in evaluate mode first.

For developers: GitHub's own teams resolve 67.3% of findings before merging. Changelog

Add-on · GitHub Advanced Security

Code scanning, secret scanning and Autofix

Finds security vulnerabilities and leaked secrets in the pull request, and Copilot Autofix proposes a fix in the same place. Push protection blocks secrets before they reach the repository.

For developers: security issues get fixed while the code is fresh, not weeks later from a ticket.

Pricing note. Code Quality and Advanced Security are separate paid products. They aren't part of the model cost example above, so those savings are model-only. Built for the enterprise

Governance, security and the Microsoft ecosystem

Governance

Controls in one place

Org-level model and feature policies, agent audit logs, content filters and CLI sandboxing. Agents work through the same repos, pull requests, pipelines and checks as your developers, so AI-written code meets the same bar.

Security and IP

Your code stays yours

Copilot Business and Enterprise don't train on or retain your code. GitHub's zero-retention agreement with Anthropic covers Claude models in Copilot, and one IP indemnity applies across every model. GitHub Advanced Security, secret scanning and Copilot Autofix sit in the same workflow.

Microsoft and Azure

Fits your existing agreement

Consumption draws down your Microsoft Azure Consumption Commitment. Connects to Microsoft Foundry, Defender for Cloud and Azure SRE Agent, and works with Azure DevOps repos.
